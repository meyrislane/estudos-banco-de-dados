# Estudos de Banco de Dados

Este repositório registra minha trajetória para me tornar DBA (Administradora de Banco de Dados). Encontrei na área de dados a carreira que quero seguir, e aqui documento cada etapa do caminho.

## O que estou estudando agora
SQL Server, com consultas no SQL Server Management Studio (SSMS) e o banco de exemplo AdventureWorks. Versiono meus estudos e projetos com Git e GitHub.

## Organização
- `sql-pratica/`: exercícios de SQL resolvidos, organizados por semana
- `projetos/`: projetos práticos de modelagem e administração de banco de dados
- `erros.md`: caderno de erros, com o que errei, por que errei e a forma correta, para revisar e fixar o aprendizado
